# SCWC 浏览器扩展隐私说明

SCWC 是将用户选择的网页内容发送到用户配置的 SCWC 核心的采集工具。扩展没有开发者托管的数据接收服务、广告、统计或遥测。

扩展保存核心地址、端口、访问令牌、网站 origin、抓取选择器、描述、文本前缀、插件控件值、外观设置和带已读状态的通知历史，位置为当前浏览器配置文件内的扩展本地存储。自动关闭的通知保留在“通知”标签页，进入历史可视区域时标为已读；主动关闭通知会删除该条历史。扩展图标通过浏览器角标显示未读数量。该存储不是浏览器账号云同步，也不在网站的 localStorage 中。

打开弹窗后，扩展将当前网站地址和网站配置发送到用户指定的核心，并在弹窗打开期间定期同步。网站配置包含访问令牌，与现有 user-script 的配置协议相同。点击采集或触发需要网页内容的插件操作时，将选中元素的文字和图片、页面 URL 及相关插件参数发送到同一核心。内容可能包含用户选择的个人信息，请只采集自己希望提交的内容。

扩展不会批量读取浏览历史、Cookie 或所有标签页，也不会将数据发送给扩展开发者。网页选择高亮只在用户主动选择或查看抓取项时启用。核心插件可能对数据进行进一步处理，其保存、转发和删除由所连接核心及其插件决定。

用户可在弹窗中删除抓取项、修改配置，也可卸载扩展清除扩展本地数据；浏览器扩展管理页面可撤回主机权限。卸载不会删除已经发送到核心的数据，核心数据需在核心所在设备管理。使用 HTTP 远程连接时传输不加密；远程部署建议配置 HTTPS。

问题反馈：[项目 Issues](https://github.com/XunJiJinag/selectively-crawl-web-content/issues)。上架前应将本说明发布到稳定可公开访问的网页，并确保商店的数据用途声明与实际部署方式一致。
