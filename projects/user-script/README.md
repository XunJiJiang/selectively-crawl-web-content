# 用户脚本

构建：`bun run --cwd projects/user-script build`。产物为 `dist/user-script/scwc.user.js`，通过核心命令 `server install-userscript` 或 Web 快速访问中的“安装油猴脚本”唤起安装。

## 网站数据同步

以网站 origin（协议、域名、端口）隔离数据，路径、查询参数和片段不参与配置身份。同源的顶层页面、不同路径及 iframe 共享配置。核心使用独立数据库 `SCWC_DATA_DIR/scwc/userscript-config.sqlite`（缺省 `data/scwc/userscript-config.sqlite`）。当前只在悬浮窗中提供编辑入口，工作台和插件页面没有该数据库的编辑界面或授权。

每个网站保存完整设置（包括核心地址和 Token）、抓取项、窗口位置和最小化/展开状态、当前插件标签及插件控件值。浏览器本地副本保存在 `__scwc_website_config__`，设置、抓取项与窗口状态同时兼容原有公共键；同源标签页和 iframe 通过 storage 事件更新。

数据包含 `version`、`website`、`updatedAt` 和 `data`。每次本地编辑立即保存并尝试同步；每次连接/重连都会与核心比较日期，取较新版本。日期相同但内容不同时以核心已有版本为准，避免双方反复覆盖。接受远端数据后，本地下一次编辑的日期始终比已接收日期晚，兼容本机时钟回退。

核心通过绑定网站 origin 的单次 WebSocket 票据通知更新，Token 只出现在认证 HTTP 请求头和配置正文中，不进入连接 URL。离线编辑保留，断线后自动重试；上传途中发生的新编辑不会被旧响应覆盖。关闭核心时保存数据库健康备份。

`updateLocalStorageFormat_2026_10_30` 将旧设置、抓取项和窗口状态迁入带日期的结构，保留旧键，重复运行不改变日期。已有旧数据首次迁移使用迁移时间；全新网站默认值使用初始日期，不覆盖核心已有配置。迁移前将旧键另存 `.before-2026-10-30` 副本；旧窗口 JSON 损坏时仍迁移可读取的设置和抓取项。

`updateLocalStorageFormat_2026_10_31_origin` 兼容短期路径版本的本地副本，按修改日期选取该 origin 最新配置恢复到版本 1 的公共键，保留路径副本且不改变修改日期。SPA 路径变化不切换网站配置和订阅，插件内容仍按各插件声明的 URL 规则决定是否刷新。

## 插件刷新时机

URL 变化时各插件按自己的声明分别决定是否重载控件，未触发的插件保留控件实例和值。进入/离开插件适用的网站范围时更新插件集合。支持 History API、前进后退、hash 及油猴隔离环境的 URL 检查；迟到响应不会覆盖新页面结果。

刷新规则由插件提供，悬浮窗不再提供全局刷新规则编辑项。旧 `plugin.refreshRule` 仅为兼容旧数据保留，不参与刷新决策。声明方式见 `projects/server/plugins/README.md`。

没有抓取项时仍向核心发送 `data: []`，由匹配的插件处理空结果。
