在聚焦某个插件页面时，底栏的前进和后退按钮一直处于禁用状态，应该根据当前插件页面的路由状态进行动态显示和禁用。且即使插件使用了单页应用路由，主页面也应该能够正确获取到插件页面的路由变化状态（在切换单页路由时不触发刷新）。
底部 .status-url-input 输入框应该显示解码后的url，如果复制进去的url是编码后的url，则应该在输入并失焦后显示解码后的url。仅当选中全部并复制时，复制到剪贴板的内容才是编码后的url。
当打开的页面被收藏时，收藏图标应该显示为实心。修改为使用 codicon 中的 star-half、star-full
将底部状态栏的高度从 24px 提高到 32px，内部元素高度不变但是要垂直居中。
底栏右侧的通知图标在没有未读通知时显示为codicon bell，有未读通知时显示为codicon bell-dot。

其他：
上下文菜单的字体较小。
在 webutils 添加一个功能，可以查看当前页面的外部状态，包括是否在 web 页面中打开，是否在浏览器中直接打开，是否聚焦（仅在web页面中打开时有值）。
当前页面中大量使用两边为圆角的按钮、圆形按钮、圆角输入框、圆角下拉框、圆角通知框、圆角通知中心、圆角快速访问框、上下文菜单等。将所有圆角元素修改为统一的圆角半径（4px）
当前上下文菜单在深色下为rgb(37, 45, 63)，修改为纯黑色+半透明+底部模糊；浅色下为纯白色+半透明+底部模糊。
在顶栏中快速访问按钮的左侧添加“返回”和“前进”按钮，点击后触发的不是浏览器的前进和后退，而是触发主页面的前进和后退功能，主页面的前进和后退记录聚焦的位置（中心区域精确到记录标签页切换、主侧边栏精确到记录侧边栏切换、底部面板精确到记录切换输出页和某个终端页），点击这两个按钮时需要检测目标位置是否存在（标签页可以被关闭导致不存在，主侧边栏页则没有不存在的可能，只需要调整状态为显示），如果目标位置不存在，则跳过该位置（并将该位置踢出历史），继续寻找下一个目标位置，直到找到存在的目标位置为止。如果都没有找到，则不进行任何操作，并禁用这个按钮，直到有新的目标位置出现。
当拖动拖拽条时，光标样式会变为“抓手”。应该继续显示为“col-resize”或“row-resize”，在拖拽时，鼠标指针也应该显示为“col-resize”或“row-resize”，而不是“抓手”。
当两条拖拽条相交时，鼠标指针应该显示为“十字”，并支持拖拽调整两个拖拽条的交点位置来同时调整两个拖拽条的控制的尺寸。
当前的通知都没有进入通知栏，应该在通知栏中显示所有通知（除非这个通知在显示未结束前被用户关闭）。当用户点击某个通知后，这个通知应该通过修改边框颜色来表示聚焦，此时这个通知不应该被自动关闭，直到用户手动关闭或失焦后重新开始关闭计时。
当某个通知没有被聚焦或关闭，则这个通知状态为未读，当这个通知在结束倒计时进入通知栏后，底部状态栏的通知图标应该显示为未读状态，直到用户点击该图标查看通知列表后，所有滚动到可视区域的通知都应该被标记为已读状态。如果打开的是未读通知，则转换为已读状态后，应该在通知列表中显示为已读状态，但是不立刻将这个通知从未读列表中移除，而是等用户切换到其他过滤条件或关闭通知列表后再将这个通知从未读列表的显示中移除。
所有字体较小的问题可能都是因为没有设置字体大小导致的，应该在根元素中设置基础字体大小为 14px，其他特定大小元素的字体大小使用 rem 单位来设置。

### 5 下一部分要求

主侧边栏：
活动栏中图标的容器相对于图标来说较大，缩小容器的大小，也同时缩小活动栏的宽度。
“页面”页面中，下方插件页面卡片的 .plugin-open-buttons 现在位于右侧，位于其他所有内容的下方。修改为和 .list-main>span>small 水平对齐，位于 .list-main>span>small 的右侧。

中心区域：
当前某个分组中标签页较多时，会先压缩标签页的宽度，直到标签页的宽度小于某个最小宽度时，才会显示滚动条。修改为不压缩标签页的宽度，而是超出宽度时直接显示滚动条。
当被主侧边栏和辅助侧边栏覆盖时，中心区域现在可以左右滚动，但是此时标签栏应该被压缩，然后标签栏内部独立控制滚动，而不是跟随中心区域的页面内容一起滚动。
重命名某个标签页时，打开中心输入框时没有填入当前标签页的名称，应该填入当前标签页的名称并选中全部。

底部面板：
当前终端输入框的位置比左侧 ">" 的位置偏上，应该和左侧 ">" 的位置垂直居中对齐。
当前在多行命令输入时，不是每一行的开头都显示 ">"，而是只显示一个，且位置在所有行的垂直居中。修改为每一行的开头都显示 ">"，且位置在每一行的开头。
输出窗口中，即使当前不位于底部，输出内容更新后也会自动滚动到底部。修改为当前已经在底部时，输出内容更新后自动滚动到底部；如果当前不在底部，则不自动滚动到底部。
当重命名某个终端时，没有在打开输入框时全部选中当前终端的名称，应该在打开输入框时全部选中当前终端的名称。

底部状态栏：
显示“当前窗口高度过低”的弹窗中的文本没有垂直居中。这个窗口受到右侧关闭按钮的影响，高度被拉高了，调低高度并垂直居中显示文本。这个窗口还覆盖了一小部分底部状态栏的内容，向上略微调整位置为不覆盖底部状态栏的内容。

其他：

快速聚焦访问窗口中，存在 ">" "#" 等特殊字符的功能。在没有输入任何字符时，应该置顶显示这些特殊字符的功能，方便用户快速访问这些功能。当选中这些特殊字符的功能时，应该在输入框中输入对应的特殊字符。
