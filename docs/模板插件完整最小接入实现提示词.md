| `ui.apis.mountStatic(path, { directory })` | 挂载插件目录内资源目录，演示根路径和嵌套路径；不能读取插件目录外内容 |

| 辅助页句柄 `setCurrentPageVisible(visible)` | 已配置合法 JSON/HTML 模板或内容提供器后才可隐藏“页面信息”；演示隐藏和恢复，非法隐藏须拒绝并保留旧定义 |

| 属性句柄 `invalidate({ tabId? })`、`dispose()` | 更改后端演示数据后触发重新投影，覆盖有/无 tabId 的调用及注销；当前 HostUI 实现未使用 target 参数，不能把全量刷新冒充精确 tab 失效，须在覆盖表标注并按必要缺口处理 |

`SidebarDefinition` 为 `{ id, title, icon, content }`；`AuxiliaryDefinition` 增加 `hideCurrentPage?`。图标为 `{ kind: 'builtin', name }` 或 `{ kind: 'asset', path }`，均给出可见示例。

`content` 支持静态 `UIContent` 和 `(RenderContext) => UIContent | Promise<UIContent>`；必须覆盖这两种来源及异步提供器。`UIContent` 为 `{ format: 'json', version: 1, root }` 或 `{ format: 'html', version: 1, html }`。`RenderContext` 含 `pluginId/instanceId/windowId/workspaceId/viewId/tabId/sourceTabId/signal`，只使用核心绑定的身份。

`HandlerDefinition` 的 `run(this: HandlerContext, ...args)` 支持同步/异步返回 JSON 值；`watch(this, args, emit)` 返回同步/异步注销函数。上下文含 `invocation/eventId/instanceId/windowId/workspaceId/source/sourceTabId/event/readValue(name)/signal`。实际演示参数、返回值、字段采集和取消，不能将 DOM、函数或 Error 对象作为返回值跨进程传输。注销会使仍被引用的绑定失效，演示中先移除引用再释放对应处理器和资源。

## 六、统一模板语法与 JSON 组件

以下语法均做可见的最小实现，并显示实际参数/返回值：

- `onclick="demo.handle"` 默认且唯一的位置参数为过滤后的 `$event`；`onclick="demo.handle($event)"` 等价；`demo.handle()` 明确为零参数。
- `onclick="demo.handle($event, 123, 'abc', $for:query)"` 展示事件、number、string 和命名输入值；`for="query"`、多个关联字段和元素自己的 `name` 都要覆盖。关联值附在 `$event.value` 或 `$event.values`，不插入不确定数量的位置参数；表单提交按声明字段采集。
- `a(...)|b($prev)` 只是普通处理器函数的串行调用；外层逗号分隔独立分支。没有独立“管道处理器类型”，不存在 `core:pipe` 注册接口。
- `$event/$prev/$for:<name>`、单/双引号转义、数组/对象字面量、同域嵌套调用、同步/异步返回，以及 `${...}` 在 HTML/JSON 中的插值。
- `null` 是合法返回值；无返回值不能被 `$prev` 或模板读取。纯单表达式 JSON 目标保持类型，混排文本遵守标量约束；对象/数组显式 `core:json.stringify(...)`。
- `${demo.read(...)}`、`${core:get('demo.reader')}`：只读处理器返回值；统一 getter 只读受注册的数据键/处理器，不能当成任意 HTTP、路径或 JS 求值接口。
- `${watch:query()}` 监听命名控件；`${watch:demo.counter(...)}` 监听插件后端；`${watch:core:get('config.validation.note')}` 和 `${watch:core:config.read('validation.note')}` 监听核心配置；`${watch:ui:demo.selection(...)}` 监听来源前端页面。
- 不存在 `core:ui:`、`watch:core:ui:`。同一调用链、嵌套参数或嵌套触发不能跨前后端传值。可以使用独立分支分别执行，但不能通过它们偷渡上一个域的 `$prev`。
- 没有绑定来源普通页面时，所有 `ui:` / `watch:ui:` 统一显示纯文本 `<无数据，需要打开插件页面>`；不借用别的同插件页面，不排队补执行业务。必须验证从插件卡片“配置”入口打开的无来源场景。
- 覆盖 click/input/change/submit/contextmenu/focus/blur 和 hover（HTML mouseenter/mouseleave；JSON hover），不要为演示引入连续 mousemove 上报。

JSON 组件逐一给出最小用法：`stack`、`text`、`icon`、`image`、`button`、`input`、`textarea`、`select`、`checkbox`、`toggle`、`form`、`progress`、`badge`、`divider`、`tabs`。Tabs 使用 `{ id, label, children }`，覆盖嵌套子标签、点击/方向键/Home/End、内容更新后保留选中项。控件覆盖 `key/name/for/events/visible` 及各自允许字段。仅使用真实编译器支持的属性，不能自行添加任意组件 props、HTML 或样式函数。

## 七、核心处理器完整清单

下面每个名字都应有最小有效用法或由合法核心 UI 间接验证，并写入覆盖表。参数与前置条件再次核对 `declarative-ui.ts`、`ui-compiler.ts` 及对应前端效果消费代码。

| 类别 | 名称和最小调用方式 |
| --- | --- |
| 字符串 | `core:string.trim(value)`、`core:string.lower(value)`、`core:string.upper(value)`、`core:string.toString(value)`；对象/数组不能用 toString 代替 JSON 序列化 |
| 数字和布尔 | `core:number.parse(text)`、`core:boolean.parse(value)`，包含无效输入反馈 |
| JSON | `core:json.parse(text)`、`core:json.stringify(value)` |
| 对象 | `core:object.get(object, ['a','b'])`、`core:object.pick(object, ['a','b'])`，禁止原型键 |
| 数组 | `core:array.first(array)`、`core:array.length(array)` |
| 缺省和规则 | `core:default(value, fallback)`（当前对 null 缺省）、`core:validate(value, rules)`；规则按 `codec/min/max/maxLength/options` 白名单 |
| 字段 | `core:value.read(name)`、`core:value.write(name, value)`，写入类型须匹配字段，展示值变化及编辑序号保护 |
| 数据 | `core:get(key)`；覆盖 `config.<key>`、`inspector.page.title` 等核心投影、已注册只读后端 getter；空键按实际实现返回实例 inspector 或 null，不能假定永远是完整快照 |
| 配置 | `core:config.read(key)`、`core:config.write(key, stringValue)`；先读取配置基线再写入，不可用最新 revision 自动掩盖冲突；所有持久值为字符串 |
| 流程 | `core:flow.stop()`、`core:event.trigger(targetName, eventName)`；目标只能是当前实例已声明命名元素，演示合法嵌套与循环/跨域拒绝 |
| 视图 | `core:view.open('mainSidebar'或'auxiliarySidebar', viewId)`、`core:view.refresh(location, viewId)`，只允许所属插件已注册视图 |
| 插件页面和配置入口 | `core:page.open(path)`、`core:settings.open()`；使用所属插件相对路径 |
| 提示层 | `core:tooltip.open()`、`core:tooltip.pin()`、`core:tooltip.close()`；在对应状态项上下文中演示 |
| 菜单 | `core:menu.open()`，在提供了 contextMenu 的状态项上下文中演示 |
| 当前实例 DOM 效果 | `core:element.focus(name)`、`core:section.toggle(name)`、`core:scroll.to(name)`；传命名目标，不传任意选择器 |
| 用户交互效果 | `core:clipboard.writeText(text)`、`core:link.openExternal(httpOrHttpsUrl)`；必须真实点击验证浏览器激活/权限，不用 hover 或模拟事件冒充用户授权 |
| 通知 | `core:notification.show(message, level?)`，level 为 info/success/warning/error |
| 核心配置表单专用 | `core:inspector.config.save($event)`、`core:inspector.config.reset($event)`、`core:inspector.config.rebase($event)`、`core:inspector.config.discard($event)`；只能通过核心“页面信息”表单操作验证，插件自定义模板不得冒充核心绑定调用 |

模板/监听只调用只读处理器。当前 `watch:core:` 支持集合以真实 `validateCall` 为准，不能给任意 `core:` 效果套 watch。副作用示例不在启动时自动执行：打开页面、外链、剪贴板、配置写入、通知创建等均由明确控件触发。

## 八、后端配置与核心“页面信息”

后端导出 `configuration`，覆盖：

- `definitions`：`id/schemaVersion/items`；item 的 `id/key/label/description/control/defaultValue/validationPolicy/rules`。控件包含 text/textarea/number/switch/select/color/readonly；用少量有意义的演示配置覆盖分组和校验，不为每个接口建立一套无关业务。
- `normalize(values)` 返回字符串映射，`validate(values)` 返回 true 或错误字符串，支持异步；`onChange(change)` 展示后端通知。
- 当前 `context.config` 的 `get(key)`、`list()`、`set(key, string, options?)`、`update(values, options?)`、`delete(key, options?)`、`reset(keys, options?)`、`subscribe(listener)` 和取消监听。它们是现有后端配置 API，作为前端写能力迁移后的唯一权威路径接入，不能在普通页面恢复对应写方法。
- `ConfigSnapshot` 的 `values/effectiveValues/revision/schemaRevision/definitions/definitionSources?`；`definitionSources` 区分 backend 与 legacy-unverified。默认值与显式值区分清楚；前端无权重新确认旧定义。
- `validationPolicy` 使用 declarative/backend-required；旧 page-required 定义须由后端显式迁移，不能假装在线页面仍能签票据。旧 legacy-unverified 定义在后端确认前不可编辑。
- 验证读写、保存、重置、后端 normalize/validate、双 revision CAS 冲突、草稿保留、接受远端值和保留草稿重新校验。后端必需校验离线时明确反馈不可用。

核心“页面信息”由核心 JSON 模板渲染，不能由插件替换，也不使用 `ui:` / `watch:ui:` 获取权威属性/配置。后端 InspectorProvider 只提供可验证的标题和字符串属性，不伪造 PID、版本、SDK 请求数或浏览器页面状态。其上下文为 `pluginId/windowId/workspaceId/tabId/locator/signal`，无 tab 时 locator 可为空。

保留辅助侧栏既有契约：

- 标题栏只有“页面信息”和当前插件自定义页两个标签，不聚合其他插件；无自定义模板或隐藏页面信息时显示单页 strong 标题。
- 标签和中心区域样式、高度一致；“页面信息”宽度固定；插件标签按文字最小宽度显示，不填满右侧，长标题才收缩省略，不横向滚动，关闭按钮固定右侧。
- 插件名称优先级：`package.json.scwc.ui.title` → 导出 name → `package.json.name` → 文件夹名称。空白跳过，不用自定义辅助页的 title 或旧导出 title 代替该名称。
- 无自定义合法模板不能隐藏内置页；注销、停用或切换插件后，不能残留上个插件的隐藏状态。刷新时辅助侧栏原本打开也必须有内容。
- layout schema 已升级到 2，保留对旧 schema 1 的迁移，不自行重命名内部 `currentPage` 标识或更改用户布局数据。

## 九、状态项、tooltip 与原生菜单

`StatusBarDefinition` 的 tooltip.content 支持 JSON、HTML 或 `{ format: 'text', text }`，也支持内容提供器；width 为可选值。用可切换的同一状态项覆盖文本/JSON/HTML 内容及异步更新，不突破每插件每区域最多一项的限制。

contextMenu 覆盖全部结构：

- item：`{ kind:'item', id, label, icon?, disabled?, action }`。
- checkbox：`{ kind:'checkbox', id, label, checked, disabled?, action }`。
- submenu：`{ kind:'submenu', id, label, children }`。
- separator：`{ kind:'separator' }`。

模板字符串可绑定 label/状态等允许字段。菜单使用工作台原有上下文菜单体系，action 仍走编译后的声明式处理器，不创建绕过权限的自制 JS 菜单。

验证紧凑状态按钮、悬停预览、点击固定、鼠标移入提示层、内容高度自适应、指向按钮的底部三角、视口边缘定位/内部滚动、Esc 和显式关闭；右键打开菜单时关闭已固定 tooltip，菜单在真实指针位置显示，支持子菜单/勾选/禁用/键盘操作。HTML iframe 内的右键坐标须正确投影到工作台，不能偏移到页面左上角。

## 十、HTML 模板必须采用核心 web 风格

不要保留默认浏览器表单或简陋白底样式。以核心 `workbench.css`、`ui-content.css` 和 `var.css` 为视觉基准：相近字体字号、暗/亮主题、背景层级、边框、间距、圆角、按钮/表单焦点态、禁用态、状态文字、属性行及滚动区域。普通模板插件页面也继续消费 `sdk.theme`，不要把页面锁死为一种主题。

HTML 模板只能使用当前编译器实际允许的标签、属性、CSS 属性/规则和主题变量；尤其要检查 `compileCSS` 的变量名前缀白名单，不能因为某个核心变量存在就假定模板允许使用。优先使用受支持的 `--surface-*`、`--text-*`、`--border-*`、`--font-*`、`--space-*` 等并提供合理回退；颜色点缀和圆角以真实白名单为准。需要资源时通过 `ui.apis.mountStatic` 和核心资源网关，不硬编码当前机器绝对地址、端口或直接加载外网 CSS。

JSON 使用核心受控组件在 Shadow DOM 内直接渲染，不接受任意 HTML/CSS/脚本；HTML 继续走 `sandbox="allow-scripts"` iframe，不授予 allow-same-origin 等额外权限。不能把 HTML 模板直接塞进宿主 innerHTML，不能用 eval/Function 执行表达式。插值始终是纯文本/安全属性；展示一次 `<img onerror=...>` 等字符串作为纯文本的验证结果。

## 十一、核心内部接口清单：通过接入间接验证，不在插件中重建

下面属于本次新增/变更的前后端传输契约。它们必须进入最终覆盖说明；正常示例使用上述 SDK/模板，由核心自动调用。普通插件页面的 page grant 不能直接取得工作台 token、创建核心实例、读取 inspector 或写配置。授权拒绝类验证放在测试中，不给页面提供绕权按钮。

### HTTP

以下路径的公共前缀为 `/web/api/workbench`，资源路径除外；认证、`x-scwc-client-window`、workspace 与 lease 按当前核心实现。

| 方法与路径 | 契约/验证点 |
| --- | --- |
| `GET /bootstrap` | 新增 capabilities：declarativeUI=1、pluginPageAPI=2、configurationWriteFromPage=false |
| `GET /ui/registry` | 贡献快照：revision、items，含所属插件/ownerEpoch、surface/id/title/icon、hideCurrentPage、状态项位置和 tooltip/menu 标记 |
| `POST /ui/instances` | pluginId/surface/viewId/workspaceId/lease?/tabId/sourceTabId/sourceFrameEpoch，核心绑定窗口及来源归属 |
| `GET /ui/instances/:id/content` | 重新编译并取得内容/绑定/renderRevision |
| `POST /ui/instances/:id/data` | renderRevision/fields/expressionBindingId?；返回 updates 和 subscriptions，前端表达式以 frontend 标记回到正确来源页求值 |
| `POST /ui/instances/:id/subscriptions` | 当前与 data 共用求值入口，不能另造监听协议 |
| `DELETE /ui/instances/:id/subscriptions/:subscriptionId` | 取消/暂停对应表达式监听；按实际 subscription 与 expressionBindingId 绑定关系验证 |
| `POST /ui/instances/:id/events` | eventId/renderRevision/bindingId/fields/event，加工作区 lease；过滤事件和字段，核心执行已编译程序，不接收任意调用 AST |
| `POST /ui/instances/:id/events/continue` | continuation/succeeded/lease，用于完成当前来源前端阶段再继续合法独立分支；不得跨域传递中间值 |
| `POST /ui/instances/:id/effects/ack` | effectId/status 确认；以当前实现为准，不宣称额外的持久化回执能力 |
| `POST /ui/instances/:id/release`、`DELETE /ui/instances/:id` | 释放实例、监听和相关资源 |
| `GET /inspector?workspaceId=...&tabId=...` | 核心页面信息快照；无 tab 时可使用 pluginId 指定所属插件，仍校验身份 |
| `POST /inspector/config/update`、`POST /inspector/config/reset` | 核心 currentPage 实例的配置事件入口，需要 instanceId、事件绑定数据和 lease；不是普通页面写接口 |
| `GET /plugins/:id/config` | 保留同插件 page grant 只读快照 |
| `POST /plugins/:id/config/update`、`POST /plugins/:id/config/reset` | 工作台权威写入，校验 baseRevision/schemaRevision；普通页面 page grant 被拒绝，不能附票据绕过 |
| `POST /plugins/:id/config/definitions`、`POST /plugins/:id/config/validation` | 旧页面能力已移除；工作台路径返回 410，普通 page grant 还可能先被授权层拒绝，不能依赖旧接口恢复注册/签票据 |
| `GET /web/ui/assets/:pluginId/:owner/{path}` | 注册资源的 cap 能力访问；覆盖图片/样式等、路径越界/过期 owner 拒绝，不能绕回插件 HTML 页面 |

实例响应包括 assetRoot/assetCapability、id、renderRevision、compiled、sourceTabId/sourceFrameEpoch、workspaceId 等。`CompiledUI` 为 `{ format, nodes, fields, events, expressions, styles }`，`format` 必须保留，用于 JSON 直接渲染与 HTML 沙箱选择。`fields` 携带 name/nodeId/kind/form；事件绑定有 id/nodeId/event/program/for/capture；表达式绑定有 id/nodeId/attribute/parts。最终 UI 效果带 id/type/args/instanceId/renderRevision。响应统一 `{ success, message, code, data }`，出错按实际错误码/状态显示，不能全部当成功。

Inspector 快照当前含 version/pluginId/tabId/coreBootId/ownerEpoch/revision/generatedAt、page.title/entryUrl、plugin.title/description/version/pid/runtimeStatus/uiBuildStatus、properties/config/diagnostics。只使用后端权威可知数据，不从普通 iframe 上报补齐这些字段。

### IPC、页面桥、事件和渲染桥

| 层 | 名称与用途 |
| --- | --- |
| 后端插件进程初始化 | Manifest.declarativeUI 承载 UIWireRegistry；含 handlers 描述、views、mounts、inspector 标记，不传函数 |
| 插件进程 → 核心 | `ui.registry` 发布原子注册快照；`ui.content` 定向更新内容；`ui.watch.changed` 通知后端监听值变化 |
| 核心 → 插件进程 | `ui.invoke`；kind 包括 handler/content/inspector/watch.start/watch.stop/cancel，按 id、参数和核心上下文路由 |
| 普通插件页面 → 工作台 | `ui.handlers.changed` 发布 revision 与页面处理器元数据；`ui.value.changed` 发送订阅值变化 |
| 工作台 → 普通插件页面 | `ui.invoke` 调用当前来源页处理器/监听，按该页处理器 revision 校验；不跨标签寻找同名处理器 |
| 主页面 → 普通插件页面 | `config.deliver` 请求交付配置并取得 revision 确认；兼容接收的 `config.changed` 事件也按 revision 去重；队列与 document/frame 代数绑定 |
| 核心工作台事件 | `ui.registry.changed`、`ui.content.changed`、`ui.data.changed`、`config.changed`、catalog 变更引发相应重取/监听更新 |
| HTML 沙箱握手 | `protocol: 'scwc-declarative-ui'`、version=1、`scwc-ui-ready`、随机 nonce、event.source 校验后建立 MessagePort；不能只信 opaque origin=null |
| 受控渲染器输入 | `init/updates/result/focus`，按 renderRevision 拒绝陈旧消息 |
| 受控渲染器输出 | `fields/event/surface`；字段快照为 `{ [name]: { value, editSequence } }`，surface 包含 click/hover/leave/contextmenu/escape、tooltip 的 resize(height)，右键带 x/y 坐标；JSON 复用同一语义，直接调用受控桥而非建立 iframe |
| 核心组件间桥 | `wb-declarative-view` 按 store/pool/pluginId/surface/viewId/tabId/sourceTabId 定位，原生菜单增加 menuX/menuY；`ui-surface-action` 传表面交互/高度，`ui-effect` 交付核心效果，`ui-executed` 发布执行回执，`ui-menu-close` 结束菜单；`DeclarativeMenu` 将已编译 JSON 菜单投影到已有工作台菜单，不作为插件前端内容写入 API |

普通页面旧 `page.update/settings.changed/config.validate` 不再作为有效内容/配置注入协议。已有页面导航、生命周期、搜索、活动与请求机制仍保留，不因为本次接入而删除或改造成辅助栏权威信息通道。
